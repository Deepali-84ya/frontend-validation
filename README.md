# Frontend Data Validation Project

## 📌 Project Overview

This project demonstrates client-side form validation using HTML, CSS, and JavaScript. The application validates user input before form submission to ensure data integrity and improve user experience.

## 🚀 Features

- Full Name Validation
- Email Validation
- Phone Number Validation
- Password Validation
- Confirm Password Validation
- Error Messages for Invalid Inputs
- Success Message on Valid Submission
- Responsive User Interface

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ✅ Validation Rules

### Name
- Required
- Minimum 3 characters

### Email
- Must follow valid email format
- Example: user@example.com

### Phone Number
- Must contain exactly 10 digits

### Password
- Minimum 8 characters

### Confirm Password
- Must match Password

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

## 📸 Expected Output

- Displays validation errors for incorrect inputs.
- Displays "Registration Successful!" when all inputs are valid.
